# ImageNet Dataset Download Instructions for BERT

## For BERT training, you will need:

1. ImageNet ILSVRC2012 Training Set
2. ImageNet ILSVRC2012 Validation Set

## Download Links:
- Register at: https://www.image-net.org/
- Download training set: ILSVRC2012_img_train.tar
- Download validation set: ILSVRC2012_img_val.tar

## Setup:
1. Extract training set to: data/imagenet/train/
2. Extract validation set to: data/imagenet/val/
3. Run preprocessing script to organize by classes

## Alternative:
Use torchvision.datasets.ImageNet for automatic download (requires registration)
