# Unit 5: Capstone Project

## Overview
The final capstone project brings together everything learned throughout the course. Create and host your own complete generative 3D model and interactive demo to receive course certification.

## Project Goals
Build an end-to-end generative 3D system that:
- Converts images to 3D representations
- Demonstrates the complete pipeline from input to output
- Is hosted and accessible as a working demo
- Showcases your understanding of the course concepts

## Requirements

### Model Component
- **Host a model** under your username: `hf.co/{username}/{model_name}`
- **Include a model card** with proper documentation
- **Tag with `image-to-3d`** pipeline tag for discoverability
- **Apply correct license** if applicable

### Demo Component  
- **Host a Space** under your username: `hf.co/spaces/{username}/{space_name}`
- **Support image input**: Accept `.png` and `.jpg` files
- **Generate 3D output**: Produce `.glb`, `.obj`, `.ply`, or `.splat` files
- **Reference your model** URL in the Space README

This is an open-ended capstone. You can choose to:
- **Build from scratch**: Create your own novel approach

- **Clone and customize**: Start with existing models and add your own features
