# Unit 0: Introduction and Overview

## Overview
Welcome to the Machine Learning for 3D Course! This introductory unit provides the foundation for understanding the current state of 3D machine learning and its importance.

## What You'll Learn
- **What's going on**: The current big picture of machine learning for 3D
- **Why it matters**: The importance of recent developments in 3D AI
- **How to do it yourself**: Preparation for building your own generative 3D demo

## Contents
- `introduction.md` - Course overview and instructor introduction
- `whats-going-on.md` - Current state of 3D AI and recent breakthroughs
- `why-does-it-matter.md` - Significance and applications of 3D AI
- `how-to-do-it-yourself.md` - Getting started with 3D AI development

## Key Concepts
- The tipping point in 3D AI similar to language and vision models
- Different approaches to representing 3D data
- The gap between 3D research and practical applications
- Overview of the generative 3D pipeline

## Prerequisites
- Basic understanding of machine learning concepts
- Familiarity with deep learning is helpful but not required

## Next Steps
