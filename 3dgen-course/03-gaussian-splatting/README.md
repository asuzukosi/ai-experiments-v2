# Unit 3: Gaussian Splatting

## Overview
This unit dives deep into Gaussian Splatting, a differentiable rasterization technique that serves as an AI-compatible 3D representation. Learn how to work with splats for real-time 3D rendering and ML applications.

## What You'll Learn
- The fundamentals of Gaussian Splatting and differentiable rasterization
- How splats differ from traditional meshes and other 3D representations
- Practical implementation and hands-on experience with Gaussian Splatting
- Real-time rendering capabilities and end-to-end 3D applications

## Key Concepts
- **Differentiable Rasterization**: AI-compatible rendering techniques
- **Gaussian Splats**: Point-based 3D representation with orientation and scale
- **Real-time Rendering**: Interactive 3D visualization capabilities
- **End-to-end Compatibility**: Integration with ML pipelines

## Why Gaussian Splatting?
Unlike other ML-friendly 3D representations (NeRFs, Triplanes), Gaussian Splats can be rendered in real-time, making them ideal for:
- Interactive 3D applications
- End-to-end AI-compatible pipelines  
- Production-ready 3D experiences
- Real-time editing and manipulation
